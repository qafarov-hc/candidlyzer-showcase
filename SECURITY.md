# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues,
discussions, social media, or other public channels.

If you believe you have discovered a vulnerability affecting CandidLyzer,
please report it privately by email:

**qafarov.dev@gmail.com**

Include as much of the following information as possible:

- a clear description of the issue;
- the affected page, endpoint, or feature;
- the steps required to reproduce it;
- the potential security impact;
- relevant browser and operating-system information;
- screenshots or request details that do not contain sensitive data.

Do not include:

- passwords;
- authentication cookies;
- access or refresh tokens;
- API keys;
- complete payment information;
- personal data belonging to another user;
- destructive proof-of-concept activity.

## Responsible testing

When investigating a possible vulnerability:

- use only accounts and data that belong to you;
- do not access or modify another user’s information;
- do not perform denial-of-service testing;
- do not send automated high-volume traffic;
- do not attempt social engineering;
- stop testing if you encounter sensitive or personal data.

## Scope

This repository is a public product and engineering showcase. It does not
contain the proprietary CandidLyzer source code or production configuration.

Security reports concerning the live product at
[https://candidlyzer.com](https://candidlyzer.com) are still welcome.

## Response

Valid reports will be reviewed as soon as reasonably possible. Additional
information may be requested to confirm and resolve the issue.

Please allow time for investigation and remediation before publicly
disclosing a reported vulnerability.
