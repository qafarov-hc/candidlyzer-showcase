# Contributing

Thank you for your interest in CandidLyzer.

## About this repository

This repository is a public product and engineering showcase. The proprietary
CandidLyzer application source code is maintained privately and is not
developed through this repository.

## Appropriate contributions

You may use GitHub issues to report:

- broken links;
- inaccurate public documentation;
- accessibility problems visible in the live product;
- reproducible user-interface problems;
- unclear product explanations;
- general feature suggestions.

Before opening an issue, please check whether a similar issue already exists.

## Pull requests

Unsolicited pull requests are generally not required for this repository.

Small documentation corrections may be considered, but acceptance is not
guaranteed. A submitted pull request does not grant access to the proprietary
CandidLyzer source code or establish a contributor, employment, or commercial
relationship.

## Security issues

Do not publish security vulnerabilities as regular GitHub issues.

Please follow the private reporting instructions in
[SECURITY.md](./SECURITY.md).

## Support

For account, subscription, billing, or personal-data questions, do not use
public GitHub issues.

Use the feedback channel inside CandidLyzer or contact:

**qafarov.dev@gmail.com**

Never post passwords, tokens, payment information, authentication details, or
personal application data in this repository.
